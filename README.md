# ✦ Gustavo Martins Tattoo — Landing Page & Web App

Landing page institucional e aplicativo web responsivo para o estúdio de tatuagem **Gustavo Martins Tattoo**, focado em conversão, agendamentos via WhatsApp, reserva de artes flash exclusivas e exibição de portfólio de alta resolução.

---

## 🎨 Características do Projeto

- **Estética Dark Luxury:** Design sombrio e sofisticado, com paleta em preto profundo (`#0c0c0c`) e acentos dourados (`#c9a44c`).
- **Tipografia Clássica:** Google Fonts (*Cinzel Decorative*, *Cinzel*, *Montserrat* e *Unifraktur*).
- **Categorias Interativas:** Blackwork, Floral, Gótica, Fine Line e Fechamentos com filtro dinâmico de portfólio.
- **Galeria & Lightbox:** Visualização ampliada de tatuagens com alta definição e botão de orçamento personalizado.
- **Catálogo Flash:** Cards em estilo pergaminho vintage com ilustrações vetoriais e valores tabelados (`R$ 300`, `R$ 350`, `R$ 400`) com reserva direta.
- **Orçamento & Agendamento Inteligente:** Modal com formulário dinâmico que gera a mensagem pré-formatada para o WhatsApp.
- **100% Responsivo & Leve:** Construído com Tailwind CSS e JavaScript Vanilla, sem dependências pesadas de backend.

---

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/mendesjulio89-code/tattoo.site.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador:
   - Duplo clique no arquivo `index.html`, ou
   - Execute com uma extensão de Live Server (VS Code / Antigravity).
